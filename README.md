# tecnomultimedia
# Juego Aumentado con Processing + Resolume

Trabajo práctico desarrollado para la materia Tecnología Multimedia — UNLP.

## Descripción
Juego interactivo con visuales generativos en tiempo real construido en Processing,
integrado con Resolume para performance en vivo.

## Tecnologías
- Processing (Java) — lógica del juego y generación visual
- Resolume Arena — integración para visualización en vivo
- Assets de imagen y sonido custom

## Estructura
- `Principal.pde` — loop principal y control del juego
- `Escenario.pde` — entorno visual generativo
- `Enemigo.pde` / `Bala.pde` — lógica de entidades
- `Base.pde` / `Estructura.pde` — clases base
